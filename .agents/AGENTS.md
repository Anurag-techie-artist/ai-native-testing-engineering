Key Principles:
1. **Scope-Lock Rule**: Implement exactly what the assignment asks for — nothing more, nothing less.
2. **Mandatory Prompt History**: Record workspace-level prompts in `WORKSPACE_Prompt_History.md` and question-specific prompts in `Q1_Prompt_History.md`, `Q2_Prompt_History.md`, and `Q3_Prompt_History.md` chronologically without editing or paraphrasing.
3. **Engineering Workflow**: Follow UNDERSTAND -> DEFINE REQUIREMENTS -> PLAN -> IMPLEMENT -> TEST -> COMPARE EXPECTED vs ACTUAL -> DEBUG -> VERIFY -> REFACTOR -> REGRESSION TEST -> DOCUMENT -> CLEAN COMMIT.
4. **Empirical Evidence**: Never claim tests or tasks pass without verified, real execution logs/evidence.
